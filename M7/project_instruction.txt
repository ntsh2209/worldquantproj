# MUST DO PROPERLY

## Strategy Return Formula

Use lagged weights:
[
R_{t+1}^{strategy} = w_t^\top R_{t+1}
]

Inline visualization helps here:
R_{t+1}^{strategy}=w_t^{\top}R_{t+1}

This shows proper execution logic.
